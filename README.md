# HVTCoder

> **Born to Code, Built to Solve.**

HVTCoder là nền tảng hỗ trợ **kiểm nghiệm và phân tích code dành cho học sinh**, được xây dựng với mục tiêu giúp việc luyện tập lập trình trở nên trực quan, nhanh chóng và dễ tiếp cận hơn.

## ✨ Tính năng

- 🧠 **Phân tích bài toán** — hỗ trợ hiểu và phân tích yêu cầu đề bài.
- 💻 **Kiểm nghiệm code** — hỗ trợ học sinh kiểm tra và đánh giá lời giải.
- 🔍 **Phân tích lỗi** — tìm và giải thích những vấn đề trong code.
- 📊 **Theo dõi kết quả** — lưu lại lịch sử phân tích và quá trình luyện tập.
- 📝 **Review lời giải** — hỗ trợ xem xét và cải thiện cách giải.
- 🤖 **AI-powered** — ứng dụng AI để hỗ trợ quá trình học lập trình.

## 🎯 Đối tượng

HVTCoder hướng tới **học sinh đang học và luyện tập lập trình**, đặc biệt là những bạn đang chuẩn bị cho các kỳ thi học sinh giỏi, thi lập trình và các cuộc thi thuật toán.

## 🛠️ Công nghệ

- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **Prisma**
- **AI API**
